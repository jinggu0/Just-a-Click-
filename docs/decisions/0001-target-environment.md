# 0001 — 지원 환경과 기준 기기

- 날짜: 2026-09-16
- 상태: 사용자 요구사항·기기 조회 완료. 짧은 합성 입력의 CPU·Vulkan 실행 확인, 장문 성능 검증 미완료

## 확정 요구사항

- Windows 10·11용 exe 데스크톱 앱을 제공한다.
- 별도 Install Manager를 제작하고 설치 과정에서 로컬 LLM을 구축한다.
- 한 건의 녹음은 최대 4시간을 지원한다. 4시간 녹음의 저장·전사·요약·취소·복구까지 검증한다.
- 모델은 별도 Install Manager가 설치 중 다운로드하여 구축한다. 사용자가 선택을 위임하여 결정했다. 오프라인 설치판은 초기 범위에 포함하지 않는다.
- 처리 시간 요구: 전사 완료 후 요약 실행부터 최종 결과 저장까지 최대 120초, 품질 우선. 전사 시간은 별도로 측정한다. 실제 달성 여부는 미검증이다. 2026-09-17 [0006](0006-lecture-first-product-scope.md)에서 녹음 종료 후 5분 노트·다시 요약 1시간 목표로 대체했고, 대상 PC를 RAM 16GB 이상 최신 노트북으로 정했다.

## 현재 PC 조회 결과

PowerShell의 `Get-CimInstance`로 현재 실행 기기를 직접 조회했다. 사용자 계정명, 일련번호 등 식별 정보는 수집하지 않았다.

| 항목 | 결과 |
| --- | --- |
| 제조사·모델 | Samsung 940XHA |
| CPU | Intel Core Ultra 7 258V, 8코어·8논리 프로세서 |
| OS에서 확인한 물리 메모리 | 약 31.5 GiB |
| GPU 보고 이름 | Intel Arc 140V GPU (16GB) |
| 현재 OS | Windows 11 Home 64비트, 10.0.26200 |
| C: 용량·여유 공간 | 약 931.2 GiB / 274.3 GiB, 조회 시점 기준 |

GPU 이름의 `(16GB)`와 WMI의 AdapterRAM 값은 실제 사용 가능한 전용 VRAM을 확정하는 근거로 삼지 않는다. 추론 백엔드의 장치 인식, 메모리 사용량 및 가속 가능 여부는 별도 검증한다. 이 기기의 결과를 최소 지원 사양이나 Windows 10 호환성 검증 결과로 간주하지 않는다.

## 후속 검증

- 짧은 입력으로 전사·요약이 실제 실행되는지 확인한 뒤 최대 4시간으로 확장한다.
- 전체 입력을 한 번에 모델에 넣지 않고 구간 처리와 통합 단계의 누락·중복을 평가한다.
- 처리 시간, 최대 메모리, 임시 파일·모델 저장 공간, 장시간 실행 안정성을 측정한다.
- Windows 10은 별도 환경에서 설치 및 핵심 흐름을 검증한다.
- GPU·NPU 가속이나 실시간 처리 가능성을 사양만으로 보장하지 않는다.
