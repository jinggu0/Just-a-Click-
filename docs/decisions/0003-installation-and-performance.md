# 0003 — 모델 설치 정책과 처리 시간 목표

- 날짜: 2026-09-16
- 상태: 설치 방식 및 2분 목표의 측정 구간 확정, 성능 미검증

## 설치 방식 결정

사용자가 방식 선택을 위임했으므로 **Install Manager가 설치 중 모델과 필요한 추론 런타임을 다운로드**하는 방식을 채택한다. 설치 관리자 자체와 대용량 모델을 분리하여 모델별 버전 관리와 실패한 파일의 재시도를 가능하게 한다. 초기에는 오프라인 설치판을 별도로 제작하지 않는다.

- 설치 전 대상 경로, 다운로드 용량, 최종·임시 저장 공간을 안내한다.
- 공식 또는 출처·배포 권한을 확인한 공급처의 파일만 사용한다. 원격 AI 추론 API는 사용하지 않는다.
- 배포 시 고정한 manifest에 버전, revision, URL, 파일 크기, SHA-256, 라이선스 참조를 기록한다. 임의로 최신 파일을 받아 실행하지 않는다.
- 임시 파일로 다운로드하고 체크섬을 검증한 후 설치 완료로 전환한다. 실패·중단 시 정상 설치본을 보존한다.
- 부분 다운로드 재개는 공급처 지원과 파일 버전 일치 여부를 확인한 경우에만 수행한다.
- STT·LLM을 설치 후 시험 실행하고 성공해야 AI 준비 완료로 표시한다.
- 기기 사양에 따른 모델 선택은 실측 평가를 통과한 모델 목록 안에서 수행한다. 메모리 용량만으로 품질을 판단하지 않는다.
- 설치 후 핵심 기능은 인터넷 없이 동작한다. 매 실행 시 다운로드를 요구하지 않는다.
- 제거 시 앱·모델과 사용자 녹음·요약의 삭제 범위를 구분한다. 사용자 데이터는 기본 보존한다.

설치 중 모델 다운로드는 최초 환경 구축에 한정한다. 이는 아직 보류 중인 자동 업데이트 기능의 구현 결정이 아니다.

## 성능 요구

사용자는 최대 4시간 녹음에 대해 **전사 완료 후 요약만 최대 2분, 높은 요약 품질 우선**으로 확정했다.

- 측정 시작: 전사가 완료된 상태에서 사용자가 요약 실행을 요청한 시점.
- 측정 종료: 최종 요약의 로컬 저장이 완료되어 사용자가 결과를 열람할 수 있는 시점.
- 포함: 작업 대기, 필요한 모델 로딩, 입력 분할, 구간 요약, 최종 통합, 결과 저장. 요약 요청 후 수행하는 첨부 자료 처리·검색도 제외하지 않는다.
- 제외: 요약 요청 전 완료한 녹음·전사, 사용자 검토 시간, 최종 결과 이후의 선택적 Notion 전송.
- 최초 실행과 캐시가 있는 실행을 구분하여 각각 기록한다. 캐시·사전 처리를 숨겨 2분 달성을 주장하지 않는다.
- 자료 첨부·외부 검색 유무별로 측정 조건을 기록한다. 옵션을 몰래 끄거나 원본을 생략하여 목표를 맞추지 않는다.

전사 시간, 자료 분석 시간, 모델 로딩, 구간 요약, 통합, 전체 시간을 각각 기록하여 병목을 확인한다. 실제 달성 여부는 아직 검증하지 않았다.

## 품질 우선의 적용

- 2분을 맞추려고 원본을 잘라 버리거나 필수 사실·구간을 조용히 생략하지 않는다.
- 속도와 품질을 각각 측정하고 둘 다 만족해야 목표 달성으로 판단한다.
- 품질 기준을 만족하지만 120초를 초과한 결과는 ‘품질 통과·시간 실패’로 기록한다. 반대 경우도 동일하게 구분한다.
- 기준 노트북에서 동시 충족이 안 되면 측정 결과와 병목을 제시한다. 시간 연장, 녹음 중 사전 처리, 모델 변경 등은 새로운 선택지이며 사용자 결정 없이 요구사항을 낮추지 않는다.
- 품질 지표와 내부 출시 임계값은 이후 확정된 [지역화 계획](../LLM-SPECIALIZATION.md)의 사실 재현율·근거 충실성·규칙 준수 등을 적용한다. 실제 평가셋의 구축과 검수는 아직 미완료다.

## 다음 검증
