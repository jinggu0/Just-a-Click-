## 2. 선택 근거

공식 카드상 Qwen3-8B는 텍스트 생성 모델이며 8.2B 파라미터, 기본 32,768 토큰 컨텍스트, 명시적인 non-thinking 모드를 제공한다. 요약 출력에 사고 과정 생성 토큰을 추가하지 않는 구성을 만들 수 있다. 이 사실만으로 한국어 요약 우수성을 보장하지는 않는다. [Qwen3-8B 공식 카드](https://huggingface.co/Qwen/Qwen3-8B).

다음은 제품 제약에 따른 설계 판단이며 실제 비교 벤치마크 결과가 아니다.

| 대안 | 판단 |
| --- | --- |
| Qwen3-4B | 가벼운 비교 기준으로 유용하지만 품질 우선 요구에 따라 8B를 개량 기반으로 선택. 4B가 실제로 열등하다고 단정하지 않음 |
| Qwen3-8B Q4_K_M | 같은 모델의 용량·속도 비교용으로만 유지. 기본은 상대적으로 보수적인 Q5_K_M 양자화를 선택하고 품질 차이는 측정 |
| Qwen3.5-9B | 공식 카드에 비전·문서 이해 기능이 포함된 비교 대안. 현재는 텍스트 중심 파이프라인과 제작사 공식 GGUF 파일 고정이 확인된 Qwen3-8B로 범위를 집중. 3.5가 더 느리거나 품질이 낮다는 판단은 아님 |
| 더 큰 모델 | 기준 노트북에서 장문 입력·120초 목표와 함께 평가할 부담이 커 첫 배포 모델로 선택하지 않음 |

Qwen3.5의 비전 기능 범위는 [공식 모델 카드](https://huggingface.co/Qwen/Qwen3.5-9B)를 참고했다. 최신 모델 전체의 우열을 판정한 결정이 아니라, 원본 출처·텍스트 역할·개량 가능성·평가 범위를 기준으로 한 확정이다.

## 3. 실행 정책

- CPU 실행을 정확성 기준으로 삼고 Intel Arc 140V에서 Vulkan을 우선 가속 검증한다. SYCL은 비교 경로로 둔다. GPU 가속 실패 시 로컬 CPU로만 전환하며 사용자에게 실행 상태를 표시한다.
- GGUF 용량은 전체 실행 메모리가 아니다. KV 캐시·버퍼·통합 GPU 사용량을 합쳐 실제 메모리를 측정한다.
- 초기 컨텍스트 예산은 16,384 토큰으로 설정하고 부족한 입력은 누락 없이 분할한다. 이는 실험 초기값이며 모델의 최대 컨텍스트를 축소한 가중치 개조가 아니다.
- non-thinking은 런타임의 채팅 템플릿 옵션으로 설정한다. 단순히 `/no_think` 문장을 붙인 것을 동일한 보장으로 취급하지 않는다.
- 초기 샘플링은 공식 non-thinking 권고인 temperature 0.7, top_p 0.8, top_k 20, min_p 0을 기준으로 시작한다. 평가 후 설정을 버전 관리한다.
- 앱에는 범용 대화 UI, 셸 실행, 자율 도구 루프를 제공하지 않는다. PDF 추출·이미지 캡처·Notion 전송은 앱이 수행하고 LLM은 제한된 구조화 결과만 반환한다.

llama.cpp는 Intel용 SYCL 경로를 문서화하지만 현재 기기의 Windows 가속 성능은 미측정이다. [공식 SYCL 문서](https://github.com/ggml-org/llama.cpp/blob/master/docs/backend/SYCL.md).

## 4. 확정과 검증의 구분

모델 선택은 확정했다. **최대 4시간 전사문을 기준 노트북에서 품질 기준과 120초 이내 요약을 동시에 만족하는지는 아직 알 수 없다.** 선택 확정은 출시 합격 판정이 아니다.

최적화 후에도 목표를 충족하지 못하면 측정 결과로 모델 변경 결정을 새로 기록한다. 입력 생략, 은밀한 저품질 모델 전환, 타이머 시작 지연으로 성공 처리하지 않는다. 현재 원본 파일을 지역화된 학습 모델이라고 부르지 않는다. 학습·검증된 파생 모델은 새 ID·revision·해시로 구분한다.

개량 절차는 [LLM 지역화 계획](../LLM-SPECIALIZATION.md), 설치용 모델 메타데이터는 [모델 manifest](../../config/llm-model.json)를 따른다.
