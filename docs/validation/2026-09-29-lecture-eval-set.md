## 1. 기준선 (초안 정답 기준)

| 지표 | 5분 노트 | 정밀 정리 | 기준 v1 |
| --- | --- | --- | --- |
| 핵심 사실 재현율(구간 겹침 대리 지표) | 15/16(93.8%) | 15/16(93.8%) | 95% 이상 |
| 일반 사실 재현율(대리) | 4/6 | 4/6 | — |
| 공지 | 정답 0, 작성 0, 없는 공지 0 | 같음(초안에서 합침) | 없는 공지 0, 재현율 100% |
| 코드 재현율 / 정밀도 | 2/17 / 2/8 | 같음 | 기준선만 |
| 올바른 용어 표기 | 전사 7/16, 노트 7/16 | | 기준선만 |
| 5분 노트 시간 | 재생이라 판정하지 않음 | | AC 녹음 300초 이하 |
| **판정** | 핵심 사실 미달(93.8%), 공지 통과 | | |

- 빠진 핵심 사실은 f15("끝까지 읽은 뒤 lseek로 오프셋을 SEEK_SET 기준 0으로 되돌린다", s54·s57)다. 두 노트 모두 그 구간을 인용하지 않았다.
- 공지 운영 단어 검사로 공지 호출이 창 6개 모두 건너뛰어졌고, 가짜 공지는 없었다.
- 코드 목록은 8개가 남았다. 정답과 맞은 것은 `SEEK_SET`·`SEEK_END` 2개다. 나머지는 이렇다.
  - `mk-node`·`mk-pico`: `mknod`·`mkfifo`의 전사 오류
  - `seek_current`: 정답은 `SEEK_CUR`
  - "exclusive flag", "file descriptor", "while loop": 여러 단어 개념어
  - 정답 쪽에서 빠진 것: 한 단어 시스템 호출(`open()` 등)은 코드 모양 검사로 지워지고, 플래그·매크로(`O_CREAT`, `S_IRUSR`)는 강의가 말로만 설명해 목록에 들어오지 않았다
- 호출 20건이 재시도 없이 모두 채택됐다. 5분 노트 개념은 5개, 정밀 정리 개념은 41개였다.

## 2. 해석

- 공지 문제는 이 강의에서 해결됐다. 다만 이 강의에는 진짜 공지가 없어 공지 재현율은 판정할 수 없었다.
- 핵심 사실 대리 재현율은 기준에 한 개 모자란다. 구간 겹침은 관대한 대리 지표다. 같은 구간을 인용하고 틀린 내용을 써도 찾은 것으로 세므로, 사람 검수에서는 더 낮게 나올 수 있다.
- 코드·용어 점수가 낮은 주원인은 전사 오류다. 올바른 용어 표기가 전사에 44%만 나온다(creat, lseek, whence, ssize_t 등이 발음대로 적힘). 노트도 같은 비율이라, 모델이 전사 오류를 스스로 고치지 못한다. 강의 자료·용어집 기반 교정이 가장 큰 개선 여지다.

3. 강의 5개가 모이면 코드·용어 목표를 정하고, 전사 용어 교정의 효과를 이 평가셋으로 잰다.
